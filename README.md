# 题库管理系统 v2.0 - AI增强版

一个功能完善的题目收集、管理和组卷系统，支持图片/PDF文件的OCR识别、**AI智能纠正**、题目分类管理、智能组卷以及Word文档导出。

**🎉 v2.0新特性**：专为**英文题目**优化，集成Claude AI进行智能纠正和解析！

## 主要功能

### 1. 智能导入 📤 ⭐ AI增强
- 支持图片格式：JPG, PNG, BMP, TIFF
- 支持PDF文档导入
- **英文优先识别**：专门优化的OCR配置，支持英文题目识别
- **AI智能纠正**：使用Claude AI自动纠正OCR识别错误
- **AI题目解析**：智能提取题目、识别题型、难度和知识点
- 自动对比显示原始OCR和AI纠正结果
- 支持文本核对和编辑

### 2. 题目管理 📝
- 按题型分类（选择题、填空题、判断题、解答题、计算题等）
- 按难度分级（简单、中等、困难）
- 灵活的标签系统（支持知识点、类别等多种标签）
- 题目搜索和筛选
- 批量导入导出
- 题目编辑和删除

### 3. 智能组卷 📋
- **手动选题组卷**：从题库中自由选择题目，自定义分数
- **自动组卷**：根据知识点、题型、难度自动筛选题目
- 支持A4和A3两种试卷尺寸
- 灵活的试卷配置（名称、说明、总分等）
- 试卷预览功能

### 4. Word文档导出 📄
- 导出标准格式试卷
- 支持A4/A3排版
- 可选是否包含答案和解析
- 导出题库文档
- 符合教学规范的排版格式

## 技术栈

### 后端
- **Web框架**：Flask 3.0
- **数据库**：SQLAlchemy + SQLite
- **OCR识别**：PaddleOCR (支持英文和中英文混合)
- **AI辅助**：Anthropic Claude API (智能纠正和解析) ⭐新增
- **PDF处理**：PyPDF2 + pdfplumber + pdf2image
- **文档生成**：python-docx

### 前端
- HTML5 + CSS3 + JavaScript
- 响应式设计
- 现代化UI界面

## 安装步骤

### 1. 克隆项目

\`\`\`bash
git clone <repository-url>
cd texts
\`\`\`

### 2. 安装依赖

\`\`\`bash
# 安装Python依赖
pip install -r requirements.txt
\`\`\`

### 3. 配置AI助手（可选但强烈推荐）⭐

AI助手可以显著提高OCR识别准确度，特别是对于英文题目。

\`\`\`bash
# 复制配置文件模板
cp .env.example .env

# 编辑.env文件，填入你的Anthropic API密钥
# 获取API密钥: https://console.anthropic.com/
nano .env
\`\`\`

在 \`.env\` 文件中配置：
\`\`\`
ANTHROPIC_API_KEY=your_actual_api_key_here
\`\`\`

**注意**：如果不配置API密钥，系统仍可正常运行，但会使用基础OCR识别，无AI纠正功能。

### 4. 初始化数据库

数据库会在首次运行时自动创建，无需手动初始化。

### 5. 运行应用

\`\`\`bash
python app.py
\`\`\`

应用将在 \`http://localhost:5000\` 启动。

## 使用指南

### 导入题目 ⭐ AI增强

1. 访问"导入题目"页面
2. 查看AI助手状态：
   - ✅ **AI助手已启用**：将使用AI智能纠正和解析
   - ⚠️ **AI助手未配置**：将使用基础OCR识别
3. 可以切换"使用AI智能纠正"开关
4. 点击上传区域或拖拽文件（支持图片或PDF，**针对英文题目优化**）
5. 系统自动进行OCR识别和AI处理：
   - OCR识别文本（英文优先模式）
   - AI自动纠正OCR错误
   - AI智能解析题目结构
6. 查看识别结果：
   - **识别文本**：AI纠正后的文本
   - **原始OCR**：未经AI处理的原始识别文本（对比用）
   - **智能提取的题目**：AI自动解析的题目，包含题型、难度、标签等
7. 查看AI纠正信息（如果启用）：
   - OCR置信度
   - AI纠正置信度
   - 具体纠正内容列表
8. 对于AI解析的题目，系统会自动识别：
   - 题型（选择题、填空题、判断题等）
   - 难度等级（简单、中等、困难）
   - 知识点标签
   - 选项（对于选择题）
9. 点击"保存此题"保存单个题目，或"保存题目到题库"批量保存
10. 必要时可以手动编辑AI识别的信息

### 管理题目

1. 访问"题目管理"页面
2. 浏览所有题目列表
3. 使用搜索框查找特定题目
4. 使用筛选条件（题型、难度、标签）过滤题目
5. 可以对题目进行以下操作：
   - **查看**：查看题目详细信息
   - **编辑**：修改题目内容、标签等信息
   - **删除**：移除题目
6. 选中多道题目后，可批量导出为Word文档

### 组卷

#### 手动选题组卷

1. 访问"组卷"页面，选择"手动选题"标签
2. 填写试卷设置
3. 使用筛选条件加载题目
4. 从可选题目列表中勾选需要的题目
5. 在已选题目列表中为每道题设置分数
6. 点击"生成试卷"
7. 预览试卷内容
8. 导出Word文档（可选择是否包含答案）

#### 自动组卷

1. 选择"自动组卷"标签
2. 填写组卷设置
3. 点击"自动生成试卷"
4. 系统根据条件自动选择题目并平均分配分数
5. 预览并导出试卷

## API接口

### 题目相关
- \`GET /api/questions\` - 获取题目列表
- \`GET /api/questions/<id>\` - 获取题目详情
- \`POST /api/questions\` - 创建题目
- \`PUT /api/questions/<id>\` - 更新题目
- \`DELETE /api/questions/<id>\` - 删除题目
- \`POST /api/questions/export\` - 导出题目

### 标签相关
- \`GET /api/tags\` - 获取标签列表
- \`POST /api/tags\` - 创建标签

### 试卷相关
- \`GET /api/exam/papers\` - 获取试卷列表
- \`GET /api/exam/papers/<id>\` - 获取试卷详情
- \`POST /api/exam/generate\` - 生成试卷
- \`GET /api/exam/export/<id>\` - 导出试卷

### 文件上传
- \`POST /api/upload\` - 上传文件并OCR识别（支持AI纠正）

### AI辅助 ⭐新增
- \`GET /api/ai/status\` - 获取AI助手状态
- \`POST /api/ai/correct\` - AI纠正文本
- \`POST /api/ai/parse\` - AI解析题目
- \`POST /api/ai/analyze\` - AI分析单个题目

## 注意事项

1. **OCR识别**：首次运行会下载PaddleOCR英文和中文模型，需要一定时间和网络连接
2. **AI功能**：需要配置ANTHROPIC_API_KEY环境变量才能启用AI辅助功能
3. **API费用**：使用Claude API会产生费用，请注意API使用量
4. **文件大小**：上传文件限制为16MB
5. **PDF处理**：大型PDF文件可能需要较长处理时间
6. **浏览器兼容**：建议使用Chrome、Firefox、Edge等现代浏览器

## 常见问题

### Q: 如何启用AI智能纠正功能？
A:
1. 访问 https://console.anthropic.com/ 获取API密钥
2. 复制 \`.env.example\` 为 \`.env\`
3. 在 \`.env\` 文件中填入 \`ANTHROPIC_API_KEY=你的密钥\`
4. 重启应用

### Q: AI功能对英文题目的识别效果如何？
A: 系统已针对英文题目进行优化：
- OCR配置为英文优先模式
- AI能识别常见OCR错误（如0/O, 1/l/I混淆）
- 自动识别英文题目结构（Question 1, Q1, 1.等编号格式）
- 智能提取选择题选项（A. B. C. D.）

### Q: OCR识别不准确怎么办？
A:
1. 如果启用了AI，系统会自动纠正大部分错误
2. 可以对比"识别文本"和"原始OCR"标签页查看AI纠正情况
3. 必要时可以手动编辑文本内容

### Q: 如何批量导入题目？
A: 可以将多道题目放在一个PDF或图片中上传，AI会自动分割和解析题目。

### Q: 能否修改已生成的试卷？
A: 当前版本不支持直接修改已生成的试卷，建议重新组卷。
