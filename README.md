# 题库管理系统

一个功能完善的题目收集、管理和组卷系统，支持图片/PDF文件的OCR识别、题目分类管理、智能组卷以及Word文档导出。

## 主要功能

### 1. 智能导入 📤
- 支持图片格式：JPG, PNG, BMP, TIFF
- 支持PDF文档导入
- 使用PaddleOCR进行高精度中文识别
- 自动提取题目内容
- 支持文本核对和编辑

### 2. 题目管理 📝
- 按题型分类（选择题、填空题、判断题、解答题、计算题等）
- 按难度分级（简单、中等、困难）
- 灵活的标签系统（支持知识点、类别等多种标签）
- 题目搜索和筛选
- 批量导入导出
- 题目编辑和删除

### 3. 智能组卷 📋
- **手动选题组卷**：从题库中自由选择题目，自定义分数
- **自动组卷**：根据知识点、题型、难度自动筛选题目
- 支持A4和A3两种试卷尺寸
- 灵活的试卷配置（名称、说明、总分等）
- 试卷预览功能

### 4. Word文档导出 📄
- 导出标准格式试卷
- 支持A4/A3排版
- 可选是否包含答案和解析
- 导出题库文档
- 符合教学规范的排版格式

## 技术栈

### 后端
- **Web框架**：Flask 3.0
- **数据库**：SQLAlchemy + SQLite
- **OCR识别**：PaddleOCR + OpenCV
- **PDF处理**：PyPDF2 + pdfplumber + pdf2image
- **文档生成**：python-docx

### 前端
- HTML5 + CSS3 + JavaScript
- 响应式设计
- 现代化UI界面

## 使用指南

### 导入题目

1. 访问"导入题目"页面
2. 点击上传区域或拖拽文件（支持图片或PDF）
3. 系统自动进行OCR识别
4. 查看识别结果，可在"原始文本"和"提取的题目"标签页之间切换
5. 核对文本内容，必要时进行编辑
6. 填写题目信息：
   - 题型（选择题、填空题等）
   - 难度（简单、中等、困难）
   - 知识点标签（用逗号分隔，如：代数,方程,二次方程）
   - 答案
7. 点击"保存题目到题库"完成导入

### 管理题目

1. 访问"题目管理"页面
2. 浏览所有题目列表
3. 使用搜索框查找特定题目
4. 使用筛选条件（题型、难度、标签）过滤题目
5. 可以对题目进行以下操作：
   - **查看**：查看题目详细信息
   - **编辑**：修改题目内容、标签等信息
   - **删除**：移除题目
6. 选中多道题目后，可批量导出为Word文档

### 组卷

#### 手动选题组卷

1. 访问"组卷"页面，选择"手动选题"标签
2. 填写试卷设置：
   - 试卷名称（必填）
   - 试卷尺寸（A4或A3）
   - 试卷说明（可选）
3. 使用筛选条件加载题目
4. 从可选题目列表中勾选需要的题目
5. 在已选题目列表中为每道题设置分数
6. 点击"生成试卷"
7. 预览试卷内容
8. 导出Word文档（可选择是否包含答案）

#### 自动组卷

1. 选择"自动组卷"标签
2. 填写组卷设置：
   - 试卷名称（必填）
   - 试卷尺寸（A4或A3）
   - 总分（默认100分）
   - 题型筛选（可选）
   - 难度筛选（可选）
   - 知识点标签（可选，用逗号分隔）
   - 题目数量
3. 点击"自动生成试卷"
4. 系统根据条件自动选择题目并平均分配分数
5. 预览并导出试卷

#### 查看已有试卷

1. 选择"查看试卷"标签
2. 浏览所有已创建的试卷
3. 可以预览或删除试卷
4. 导出试卷为Word文档

### 导出功能

#### 导出试卷

- **不含答案版本**：适合考试使用
- **含答案版本**：适合教师批改或学生练习

#### 导出题库

在题目管理页面，选中多道题目后点击"导出选中题目"，可将题目导出为Word文档，方便整理和打印。

## 数据库结构

### 主要数据表

- **questions**: 题目表
  - 题目内容、题型、难度、答案、解析、来源等

- **tags**: 标签表
  - 标签名称、类型（知识点/类别）、描述

- **question_banks**: 题库表
  - 题库名称、描述

- **exam_papers**: 试卷表
  - 试卷名称、尺寸、总分、说明

- **关联表**: 题目-标签、题库-题目、试卷-题目

## API接口

### 题目相关

- `GET /api/questions` - 获取题目列表
- `GET /api/questions/<id>` - 获取题目详情
- `POST /api/questions` - 创建题目
- `PUT /api/questions/<id>` - 更新题目
- `DELETE /api/questions/<id>` - 删除题目
- `POST /api/questions/export` - 导出题目

### 标签相关

- `GET /api/tags` - 获取标签列表
- `POST /api/tags` - 创建标签

### 试卷相关

- `GET /api/exam/papers` - 获取试卷列表
- `GET /api/exam/papers/<id>` - 获取试卷详情
- `POST /api/exam/generate` - 生成试卷
- `GET /api/exam/export/<id>` - 导出试卷

### 文件上传

- `POST /api/upload` - 上传文件并OCR识别

## 注意事项

1. **OCR识别**：首次运行会下载PaddleOCR模型，需要一定时间和网络连接
2. **文件大小**：上传文件限制为16MB
3. **PDF处理**：大型PDF文件可能需要较长处理时间
4. **浏览器兼容**：建议使用Chrome、Firefox、Edge等现代浏览器

## 常见问题

### Q: OCR识别不准确怎么办？
A: 可以在识别后的"原始文本"标签页中手动编辑文本内容，然后再保存。

### Q: 如何批量导入题目？
A: 可以将多道题目放在一个PDF或图片中上传，系统会尝试自动分割题目。如果自动分割不准确，可以在"原始文本"中手动复制单道题目内容。

### Q: 能否修改已生成的试卷？
A: 当前版本不支持直接修改已生成的试卷，建议重新组卷。可以先删除旧试卷，再创建新试卷。

### Q: Word文档格式能否自定义？
A: 当前使用标准教育格式，如需自定义，可修改 `backend/export/word_exporter.py` 文件。
